# Restaurant Mini App

A simple consol-based restaurant billing program written in C. It lets you generate customer invoices, view all saved invoices  and search for a specific invoice.

## Features

- **Generate invoice:** you can search by invoice number and thereafter the system will require to enter your name, ordered items, and will  calculates the total.
- **Show all invoices:** list every invoice that has been saved.
- **Search invoice:** find an invoice by customer name.



## Requirements

- A C compier such as GCC 

## How to run it

```bash
gcc resto_fixed.c -o resto
.\resto

````

But on windows PowerShell, run it using:.\resto.exe

## HOW TO USE IT

When the program starts, a menu appears:

1. Generate Invoice
2. Show All Invoices
3. Search Invoice
4. Exit


Type the number of your choices and follow the prompts.
